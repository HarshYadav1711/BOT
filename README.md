# 🎭 Cultural Cell UCER — ENIGMA 2026 Official Recruitment Portal

Official recruitment and interview management web application for **Cultural Cell UCER** (United College of Engineering and Research, Prayagraj) for their flagship annual fest **ENIGMA 2026**.

---

## 🚀 How to Run the Website Locally

### Step 1: Open Terminal in the Project Folder
1. Press `Win + R`, type `powershell` or `cmd`, and press Enter.
2. Navigate to the project directory:
   ```powershell
   cd "c:\Users\himan\OneDrive\Desktop\BOT"
   ```

### Step 2: Start the Development Server
Run the following command:
```powershell
npm run dev
```

### Step 3: Open in Browser
Once the terminal displays:
```
  ➜  Local:   http://localhost:5173/
```
Open your web browser (Chrome / Edge) and visit:
👉 **[http://localhost:5173/](http://localhost:5173/)**

## 🔒 Admin Executive Panel Access

- The Admin Console is **strictly private and password-protected**.
- To access it: Click **"Admin Login"** in the top-right corner of the website.
- Enter your confidential executive credentials.
- **Change Password**: Once logged in, click the **"Change Password"** button in the top admin bar to set and update your own private password anytime.

---

## 🌟 Key Features

### 1. Public Student Registration (No Login Required)
- Open to all 2nd and 3rd-year students of UCER.
- 2nd years apply for **Volunteer / Junior Coordinator** roles.
- 3rd years apply for **Domain Head & Leadership** roles.
- **Previous Enigma Question**: 3rd-year students have a conditional field to state their previous year Enigma contributions.
- Instant printable candidate pass with unique Application ID (e.g. `ENIGMA-2026-H3011`).

### 2. Application Status Tracker
- Any applicant can enter their Roll Number or Application ID via **"Check Status"** to view their real-time interview schedule or selection announcement.

### 3. Executive Scrutiny & Interview Management
- Search, filter by domain, and review applicant dossiers.
- Schedule interview dates, time slots, venues, and assign scorecards.
- **1-Click WhatsApp Communication**: Send pre-formatted interview invites and selection letters directly to candidate WhatsApp numbers.
- **Export to CSV**: Download the full applicant roster for Excel/Sheets.
